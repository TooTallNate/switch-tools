New `@tootallnate/gfmsg` package for Game Freak's encrypted message text (`.dat`) and AHTB label hash tables (`.tbl`). nx-archive now shows a game's text as a searchable table, with each line labelled from the matching `.tbl`, and previews other AHTB tables such as flag, zone and trainer names.
