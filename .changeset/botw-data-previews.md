More game data gets real previews instead of hex:
- BFEVFL event flows and timelines.
- BotW STAT stats and ecosystem maps, rendered as images.
- PrOD placements, RSTB, XLNK link databases, far-model culling lists and sound configs.
- Shader archives, Switch tickets and certificates, and XML.
- GX2 (Wii U) and NVN textures, which also count as images in the library.
- BotW engine files with no known format (camera tracks, sky data, speed tables), which get an identification page.
